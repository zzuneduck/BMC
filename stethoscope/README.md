# 🩺 너만을 위한 청진기

등록한 **병원·원장 키워드**로 **네이버 블로그 · 유튜브 · 인스타그램 · 스레드**의 신규 게시물(본문 + 영상 스크립트)을
**매일 18시(KST)** 자동 수집하고, **의료법 제56조 체크리스트**로 `명백 / 애매 / 해당없음` 판정 →
건별 검토(수정·승인·반려) → **승인 건만 병원별 PDF**로 묶어 **주 1회 관할 보건소로 발송**하는 도구입니다.

## 1. 실행 (입력만 하면 바로)

| 환경 | 방법 |
|---|---|
| macOS | `start.command` 더블클릭 (막히면 우클릭 → 열기) 또는 터미널에서 `bash start.sh` |
| Linux | `bash start.sh` |
| Windows | `start.bat` 더블클릭 |
| 서버(항상 켜두기, 권장) | `cp .env.example .env && docker compose up -d` |

처음 실행 시 패키지·브라우저(Chromium)를 자동 설치합니다 (Python 3.10+ 필요).
브라우저에서 **http://localhost:8000** 접속 후:

1. **설정** – 쓰는 채널의 키만 입력 (없어도 네이버·유튜브는 동작)
2. **병원 관리 → + 병원 등록** – 병원명, 원장 이름, (선택) 공식 계정, 관할 보건소 이메일
3. 끝. 다음 18:00에 자동 수집됩니다. 바로 보려면 대시보드의 **지금 수집·분석 실행**.

> 🍎 **Mac 상시 실행**: `bash mac-autostart.sh` 한 번 실행하면 백그라운드 서비스로 등록돼 터미널을 닫거나 재부팅해도 계속 동작합니다 (`~/stethoscope`로 옮겨 설치, 해제는 `bash ~/stethoscope/mac-autostart.sh uninstall`). 18시에 맥이 잠자기 상태면 수집이 깨어난 뒤로 밀리니 잠자기 방지를 켜두세요.
>
> ⏰ 자동 수집은 프로그램이 켜져 있어야 동작합니다. 18시에 꺼져 있었다면 다음에 켤 때 그날 분량을 바로 따라잡아 실행합니다.
> 상시 운영은 Docker(`restart: unless-stopped`)나 항상 켜진 PC/서버를 권장합니다.

## 2. 채널별 준비물

| 채널 | 키 없이 | 키를 넣으면 |
|---|---|---|
| 네이버 블로그 | 통합검색 페이지로 최근 1주 수집 | [네이버 검색 API](https://developers.naver.com/apps) (무료, Client ID/Secret) – 더 안정적 |
| 유튜브 | `yt-dlp` 날짜순 검색 | YouTube Data API v3 키 |
| 인스타그램 | – | Graph API: 비즈니스 계정 ID + 액세스 토큰 (해시태그 검색 + 공식 계정 `business_discovery`) |
| 스레드 | – | Threads API 액세스 토큰 (`threads_keyword_search` 권한) |

- **영상 스크립트**: 유튜브는 업로드 자막 → 자동 자막 → 둘 다 없으면 **STT(faster-whisper)** 순으로 만들고, 모든 문장에 타임스탬프가 남습니다. 인스타 릴스·스레드 영상도 STT. STT 모델은 처음 사용 시 자동 다운로드(설정 `STT_MODEL`, 기본 `small`).
- **Claude 2차 판정(선택)**: 설정에서 `ANTHROPIC_API_KEY` 입력 + `LLM_ENABLED=켜기`. 규칙 엔진 후보를 Claude가 재검토하고, 원문에 없는 문장은 자동으로 버립니다. 거절(refusal) 시 서버 측 폴백(`fallbacks: "default"`)을 사용합니다.

## 3. 동작 방식

```
매일 18:00 ─▶ 병원별 검색어(병원명 · "원장명 원장" · "병원명 원장명" · 추가 키워드) × 4개 채널
            ─▶ 이미 본 게시물 ID는 건너뜀 (본문·STT 재수집 없음)
            ─▶ 본문 + 스크립트 수집 → 작성자 구분 → 56조 판정
            ─▶ 명백·애매: 화면 캡처 / 명백: 건별 PDF 생성
검토 화면 ─▶ 위반 문장·조항·타임스탬프·의견 수정, 문장 추가, 등급·작성자 구분 변경 → 승인 / 반려
주 1회   ─▶ 미발송 승인 건 → 병원별 PDF → 관할 보건소 메일 (SMTP 미설정 시 PDF만 만들고 '수동 발송' 표시)
```

- **중복 방지**: URL 변형(`m.blog`, `PostView`, `youtu.be`, `shorts` 등)을 하나의 ID로 정규화하고, `seen_refs`·`posts(platform, external_id)`·`judgments(post_id)` UNIQUE 제약으로 같은 게시물은 두 번 수집·판정되지 않습니다. 발송한 건은 다시 발송되지 않습니다.
- **작성자 구분**
  - `병원 공식 계정`: 등록한 공식 계정과 일치하거나 작성자명에 병원명 포함
  - `대가성 체험단`: "소정의 원고료", "협찬", "체험단", "#광고", "제공받아 작성" 등 대가 표시 문구, 레뷰·리뷰노트 등 체험단 플랫폼 링크/배너
  - `일반 후기`: 그 외
- **등급**
  - `명백`: 공식 계정·체험단(=광고 주체) 게시물에서 금지 표현(강) 발견
  - `애매`: 일반 후기의 금지 표현, 또는 맥락 판단이 필요한 표현(약)만 발견
  - `해당없음`: 병원·원장 언급이 없거나 체크리스트 해당 문구 없음
- **체크리스트**: `app/law56.py` – 제56조 제2항 제1~15호(치료경험담, 거짓, 비교, 비방, 수술 장면, 부작용 누락, 과장, 근거 없는 명칭, 기사형, 심의 미필, 외국인 유치, 비급여 할인, 상장·추천, 환자 유인 등)
- **PDF**: 게시물 URL, 게시·수집·캡처 시각, 작성자 구분, 위반 의심 문장(영상은 `[mm:ss]`), 근거 조항, 검토 의견, 캡처 이미지. 한글 폰트(나눔고딕) 임베딩.
- **캡처**: Chromium으로 실제 화면을 캡처하고, 로그인 벽 등으로 실패하면 수집 원문을 렌더링한 '증거 카드'로 대체해 항상 캡처가 남습니다.

## 4. 다운로드 / 발송

- 병원 관리 → 병원별 **승인 건 PDF** (기간 지정 가능)
- 병원 관리 → **승인 건 전체 ZIP** (병원별 PDF 묶음)
- 보건소 발송 → **지금 발송** / 발송 이력·PDF 재다운로드
- 주간 자동 발송은 설정 → 일정 → `WEEKLY_SEND_ENABLED=켜기` (기본 월요일 09:00). Gmail은 [앱 비밀번호](https://myaccount.google.com/apppasswords) 사용.

## 5. 명령줄

```bash
python -m app serve          # 웹 + 스케줄러
python -m app run-now        # 지금 수집·분석 1회
python -m app dispatch-now   # 지금 주간 발송 1회
pip install -r requirements-dev.txt && pytest   # 테스트
```

데이터는 `data/` (SQLite DB, 캡처, PDF)에 저장됩니다. 백업은 이 폴더만 복사하면 됩니다.

## 6. 한계 / 주의

- 자동 판정은 **보조 수단**입니다. 보건소 발송 전 반드시 검토자가 승인한 건만 나갑니다.
- 블로그 이미지 안의 글자(예: 원고료 표기 이미지)는 읽지 않습니다 → 체험단 플랫폼 배너 링크로만 탐지. 놓친 경우 검토 화면에서 작성자 구분을 바꿔주세요.
- 인스타그램 해시태그 검색은 Graph API 정책상 7일에 30개 해시태그까지입니다.
- 네이버 키 없이 쓰는 통합검색 방식은 네이버 화면 구조가 바뀌면 동작이 멈출 수 있으니 검색 API 키 사용을 권장합니다.
